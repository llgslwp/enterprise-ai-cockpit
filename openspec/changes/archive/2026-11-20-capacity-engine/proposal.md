# Proposal

## Why

「智能辅助决策」问「以现有资源最多能生产多少把 71-75」时跑偏：模型没有「可产数量」工具，只能硬套最接近的 `query_gap`，用「成品计划 707 − 活动齿块缺口 610 = 97」硬凑出错误答案（单位都不对：把数减件数），瓶颈件也找错（答「活动齿块」，实为「自由钳外管」）。

根因是**能力缺失**：agent 工具层只有「库存 / 缺口 / 完成率」三个只读工具，缺一个「现有资源可产数量」的确定性工具。模型被提示词逼着「数据问题必须调工具、严禁反问」，无工具可用只能硬凑。

## What Changes

- **ADDED `agent-core` 产能查询工具 `query_capacity`**：用确定性代码计算「现有资源可产数量」，返回「可产把数 + 瓶颈件 + 两维明细」，替代模型硬凑。
- **产能计算口径（两维，2026-11-20 业务方口述锁定）**：
  - 第一维度（装配）：1 把 = 1 组装简易钳体(装配I) + 1 活动齿块(半成品H) + 1 自由钳外管(半成品H)，取 min。
  - 第二维度（组装追加，触发 = 齿块和外管都有剩余）：1 简易钳体 = 2 固定钢板(毛坯C) + 1 活动钳体(H) + 1 夹紧头(H) + 2 长销子(H) + 1 短销子(H) + 2 组装齿块+方块座(H)，floor(min(现有量÷用量))，追加 = min(可新组, 剩余齿块, 剩余外管)。
- **产能计算口径（组合件递减多维 min，2026-11-20 业务方口述锁定）**：
  - **钻杆钳两维**：第一维度（装配）1 把 = 1 组装简易钳体(装配I) + 1 活动齿块(半成品H) + 1 自由钳外管(半成品H)；第二维度（组装追加，触发 = 齿块和外管都有剩余）用配件再组装简易钳体追加。
  - **加力钳三维**：第一维度 = 三合一组合件(钳体+外管+小钳口, 装配I) + 5 补件；第二维度 = 二合一组合件(钳体+外管, 装配I) + 6 补件；第三维度 = 8 件半成品裸件凑装（外管取待处理+半成品）。每维 = min(组合件, 补件)，补件维度间顺序消耗。
- **统一产能引擎 + 配置驱动**：产能计算逻辑抽成通用引擎，BOM（各维度配件及用量）下沉为品类配置；`capacity.py` 现有实现改造为配置驱动骨架（为阶段 2 多品类复用铺路）。
- 复用既有确定性数据读取 `gap_stat.extract_gap_stat`，不重写排产结果解析。

## 本次范围边界（阶段 1）

- **本次做**：
  - 钻杆钳**两个独立规格** 54-56、71-75 的产能计算（两维）；
  - 加力钳**公制规格 95D** 的产能计算（三维）；
  - `query_capacity` 工具 + 配置驱动骨架 + 提示词止血（禁止拿缺口硬凑可产数）。
- **本次不做（阶段 2 及后续）**：
  - 钻杆钳借件规格 89-95、114-117（齿块/外管「见71-75」，与 71-75 共享库存，需竞争分配）；
  - 钻杆钳借用规格（成品计划 = 0：139-146 / 86-91 / 58-62 / 108-110，不单独排产）；
  - 加力钳其余规格（80D / 108D / 132D / 152D / 195D / 英制 18"24"36"48"）——108D/152D 为借用规格（借 95/132），英制与公制共享件，均留阶段 2；
  - 美式 J/K、内管钳、套管钳品类；
  - 跨品类借用（内管钳/套管钳借钻杆钳外管）、组合件蕴含、外管焊接、毛坯规则、借件规格竞争分配。

> ⚠️ 口径勘误（2026-11-20 晚）：本 change 最初把「阶段 2」写成「顺序贪婪竞争 + L1/L2/L3（复用加力钳 MRP 脚本）」——**该口径已作废**。业务方口头确立的正确口径是「**组合件递减多维 min**」：装配是分步的（先把若干件预装成组合件），产能按「组合件已装到哪一步」分维度，每维 = min(组合件数量, 各补件可用量)，维度间顺序消耗补件。钻杆钳两维、加力钳三维是同一套逻辑，仅预装层级数不同。加力钳旧的 `MRP加力` 脚本（顺序贪婪 + L1/L2/L3）不再作为参照。

## Capabilities

### Modified Capabilities

- `agent-core`：新增「产能查询工具」requirement（ADDED）。

## Impact

- **数据源**：`data/raw/半成品生产计划V2.0.xlsx`（与 `query_gap` 同一份；钻杆钳读 C/H/I，加力钳读 C/H/I/F 现有量）。
- **依赖既有能力**：`semi-finished-planning`（`gap_stat.extract_gap_stat` 提取，已 0 差异验证）。
- **性能**：单规格 `calc_capacity` 实测 ≤200ms；全规格循环只读一次文件，已从 1258ms 优化到 ~132ms（≤200ms 约束）。
- **真值锚点**：54-56 = 210（瓶颈=组装简易钳体）、71-75 = 627（瓶颈=自由钳外管）、加力 95D = 1176（945+231+0，瓶颈=三合一/内管镀锌/钳体），均来自真实台账快照，非自设输入。
- **不引入**：新数据源、新第三方依赖。
