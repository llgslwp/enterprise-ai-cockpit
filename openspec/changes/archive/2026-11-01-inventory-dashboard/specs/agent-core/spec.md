# Spec Delta

## ADDED Requirements

### Requirement: 重点规格自然语言查询
系统 SHALL 支持通过自然语言查询重点关注规格：当用户以「重点规格」「重点关注」等表达发起查询时，识别为 query 意图并返回重点规格的本月入库/出库/结存数据摘要。

#### Scenario: 查询重点规格
- **WHEN** 用户以自然语言询问「重点规格有哪些」等
- **THEN** 系统 MUST 识别为查询意图，并返回重点关注规格的数量、三项合计及逐规格的本月入库/出库/结存

#### Scenario: 无勾选时提示
- **WHEN** 重点规格清单中无任何勾选
- **THEN** 系统 SHALL 返回提示引导用户去清单勾选，而非返回空数据或报错
