# Proposal

## Why

需求说明书的三大功能中，生产管理已完成，库存管理仍是空壳占位（`modules/inventory/router.py` 仅返回「待落地」）。库存数据地基（`inventory-data-model`）已就位——五类 ERP 库存 + 成品台账的读取层和字段字典都建好了，但「反映库存状态」的业务能力（看板、明细查询、预警）尚未实现。现在是补齐这块、让保管员和总经理真正能看到物资库存全貌的时机。

## What Changes

新增库存管理能力，覆盖三类交付形态，均基于 `data/raw/` 本地文件实时读取（沿用既有数据实时性约束，不缓存、不写死）：

- **库存汇总看板**：按五类 ERP 库存（毛坯/半成品/外协/车间在产品/在产品装配）+ 成品台账汇总，展示各类别的物资数、总存量等全局概览。
- **逐物资明细查询**：按货品名称/规格检索某一物资在各类库的存量、批号、库位明细。
- **库存预警**：对「主要产成品的结存低于库存底线」的规格标红提醒。底线由用户维护在一张独立的 Excel「库存底线配置表」中（按「类别+规格+特征」三维定义底线值，结存口径取台账「年末库存」字段），采用**开口式**机制——每次统计库存时扫描该配置表，仅对已定义底线的规格做预警，未定义的规格静默跳过；用户随时往配置表新增底线行，下次统计即自动生效，无需改代码。

## Capabilities

### New Capabilities

- `inventory-status`: 库存状态展示与预警能力。从五类 ERP 库存与成品台账读取数据，提供汇总看板、逐物资明细查询与「成品结存低于库存底线」的预警（底线由独立的开口式 Excel 配置表驱动），供保管员与总经理查看物资库存全貌。

## Impact

- **新增代码**：`modules/inventory/` 实现看板聚合、明细检索、预警判定三个接口，复用 `app/data_model/` 已有读取层（`load_category` / `load_all` / `load_product_ledger`）。
- **依赖既有能力**：`inventory-data-model`（读取 6 类库存数据）、`data-access`（读本地已导出文件，不连 ERP / 腾讯文档）。
- **数据实时性约束**：每次查看前重读 `data/raw/` 下最新文件，不得缓存或复用上次读取的行数与数值（沿用既有约束）。
- **库存底线配置表（开口式）**：预警阈值由用户维护在一张独立 Excel 表（`data/raw/` 下，字段为「类别/规格/特征/库存底线」），每次统计时扫描该表；未定义的规格不做预警。配置表是数据而非代码，新增底线行即时生效。
- **不引入**：腾讯文档 API 对接、ERP 对接、数据清洗。
