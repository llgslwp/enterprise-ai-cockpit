# 设计说明：入库类型语义提示与智能建议

## 方案选型

目标是「减少标错」，两条路可选：

| 方案 | 优点 | 缺点 | 取舍 |
|---|---|---|---|
| A. 后端 LLM 语义分类 | 准确率高、能读正文 | 引入 LLM 延迟、成本、不确定性；上传是高频操作 | 否 |
| B. 前端关键词规则 | 零延迟、零成本、可解释、可维护 | 只读文件名，不读正文；规则需人工维护 | **采用** |

选 B 的原因：管钳厂知识库的三类边界清晰、文件名命名有规律（含「工艺/制度/标准/指导书」等强信号词），关键词规则足够覆盖绝大多数场景；且「智能建议」只是辅助，最终仍由用户确认，不强制。

## 三类语义边界

- **工艺类**：产品怎么造（工艺、作业指导、操作规程、工序、组装、钎焊、BOM、规格参数）
- **制度类**：公司怎么管（考勤、薪酬、考核、岗位职责、管理制度、工作思路、人事行政）
- **知识类**：通用科普（行业标准 GB/QB、术语、原理、手册、指南）

## 关键词规则设计

- 制度类关键词：制度、管理、考勤、请假、报销、薪酬、考核、绩效、岗位、职责、离职、人事、行政、规定、办法、工作思路、守则、奖惩、福利、社保、通知等
- 工艺类关键词：工艺、作业指导、操作规程、工序、组装、钎焊、焊接、镀、加工、热处理、BOM、规格、参数、夹具、模具、喷砂、抛丸等
- 知识类关键词：标准、GB、QB、术语、原理、科普、手册、指南、技术背景、资料、材料、性能等

**关键优化**：知识类强信号词（标准、GB、QB、原理、术语、手册、指南、科普）权重 ×2。原因是「钳/管钳/钻杆」等产品名过于泛化，若不给「标准/原理」等词加权重，会把「管钳行业标准 QB_T2508」这类科普文件误判为「工艺类」（命中「钳」）。加权重后，强知识类信号优先。

**优先级**：强知识类信号 > 制度类 > 工艺类（同分时）。

## 数据流

```
用户选文件 → 点击「智能建议」→ suggestType(文件名)
  → 遍历三类关键词计分（知识类强信号 ×2）
  → 取最高分类型（同分按 制度>工艺>知识）
  → 命中则自动填入 uploadType + 显示命中关键词；未命中则提示人工确认
```
