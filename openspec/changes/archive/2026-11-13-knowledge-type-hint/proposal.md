# 入库类型语义提示与智能建议

## Why

知识管理的「入库类型」直接影响语义路由的域过滤：标错类型会导致文件已入库、已进索引，却因域过滤被漏检、问答永远搜不到（已发生的真实案例：《质量管理体系建设_工作思路与管理制度.docx》被标「工艺类」，实际应属「制度类」，导致提问时被路由漏检）。

当前上传界面的「入库类型」仅是一个裸下拉框，无任何语义说明，用户靠猜选择，标错率高。

## What Changes

在知识管理页「入库类型」字段上增加两层辅助，降低标错率：

1. **语义提示**：为三类（工艺类/制度类/知识类）各配「定义 + 典型例子 + 反例」，通过 hover 浮层和当前选中类型的实时说明展示。
2. **智能建议**：按文件名关键词规则给出建议类型，点击自动填入下拉框。

纯前端实现，不改接口契约、不引入后端依赖或 LLM 延迟。

## Impact

- 能力：knowledge-management（增强「入库类型标注」requirement）
- 不涉及 system-platform / 其他能力
- 不改动任何 API 契约
