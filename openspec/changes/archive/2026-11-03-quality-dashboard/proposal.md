# Proposal

## Why

企业 AI 驾驶舱的三大业务模块中，生产管理与库存管理已完成，质量管理仍是空壳占位（`modules/quality/router.py` 仅返回「待落地」）。总经理需要一眼看到车间抽检的月度质量态势与原料来料检验情况，但目前没有任何质量可视化能力。现在补齐质量模块，让高管能实时掌握合格率趋势、问题分布与来料质量，是完成驾驶舱「生产—质量—库存」闭环的最后一块。

## What Changes

新增质量管理能力，面向高管提供**只读质量看板**（第一阶段），均基于 `data/raw/` 本地 Excel 实时读取（沿用既有数据实时性约束，不缓存、不写死，**不接腾讯文档 API**）：

- **车间抽检质量看板**：按月份子表聚合「车间各工序质量抽检记录表」，展示当月总合格率、严重预警批次、分工段合格率三个 KPI，以及月度合格率趋势折线、四个维度（问题描述/配件/工段/姓名）的问题分布 TOP 横向柱状图、严重预警明细列表。
- **原料来料检验子功能**（本期包含）：按「检验日期」过滤「毛坯来料检验记录 v2」，展示检验结果分布、供应商表现、物料/问题 TOP、退货+让步预警。
- **月份回退兜底**：当月无数据时回退到最近可用月展示，并附 `note` 说明「看的是哪个月」。
- **数据来源标注**：页面标注数据源文件与最后更新日期（沿用库存模块的「数据更新日期」呈现方式）。

**明确不在本期范围（第二阶段）**：
- 完整根因分析业务规则（六分类/三分级/四预警/建议动作映射，来自 `00-质量分析规则.md`）——本期只做看板统计口径（§3），完整报告规则留待第二阶段。
- 腾讯文档在线读取、数据写回。

## Capabilities

### New Capabilities

- `quality-dashboard`: 质量看板能力。从本地「车间各工序质量抽检记录表」与「毛坯来料检验记录 v2」读取数据，提供车间抽检月度质量看板（KPI + 趋势 + 问题 TOP + 严重预警）与原料来料检验看板，并支持月份选择与缺月回退，供高管查看质量态势。

## Impact

- **新增代码**：`modules/quality/` 实现质量看板聚合接口（车间抽检 + 原料检验），复用 `plan_file_utils` 的 WPS 坏样式修复与文件定位能力。
- **新增前端**：`web/src/views/Quality.vue` 质量大屏页（含月份选择器、KPI、ECharts 图表、预警列表、原料检验分区），接入路由与侧边栏。
- **数据源**：`data/raw/车间各工序质量抽检记录表.xlsx`（月份子表，WPS 坏样式需修复）与 `data/raw/毛坯来料检验记录v2.xlsx`。
- **依赖既有能力**：`system-platform`（FastAPI 路由 + Vue 大屏框架）、`data-access`（读本地已导出文件，不连腾讯文档/ERP）。
- **数据实时性约束**：每次查看前重读 `data/raw/` 下最新文件，不得缓存。
- **不引入**：腾讯文档 API、根因分析完整业务规则、数据写回。
