# Proposal

## Why

宏润管钳厂现有 ERP 系统只能记录物资流转与工人工作量，缺少 BOM 功能与生产计划管理基础，且历史异常数据杂音大，无法支撑生产计划制定与过程管理。本项目以 Web 应用形态建设企业 AI 驾驶舱，本次变更先落地系统底座（Web 运行框架、单管理员登录、数据接入约定），为后续生产管理、库存管理、质量管理三个功能模块提供统一地基。

## What Changes

- 建立 Web 应用的整体运行框架，作为驾驶舱的统一承载底座。
- 建立单管理员登录能力，作为访问生产、库存、质量数据的统一入口（本次仅单一管理员账号，不做多用户/多角色）。
- 建立数据接入约定：数据进入本项目前已经过处理，本项目不做 ERP 系统对接、不做 ERP 导出数据清洗。
- 明确后续生产管理、库存管理、质量管理三个模块将基于本底座逐步落地（不在本变更内实现）。

## Capabilities

### New Capabilities

- `system-platform`: 驾驶舱作为 Web 应用的整体运行约束与模块承载边界，定义五大能力中本次范围内三模块（生产/库存/质量）与登录的归属。
- `admin-auth`: 单管理员账号登录能力，作为访问生产、库存、质量数据的统一前置入口。
- `data-access`: 数据接入约定，固化「数据进入前已处理、不做 ERP 对接、不做数据清洗」的边界契约。

## Impact

- **系统形态**：Web 应用。
- **数据前提**：数据进入本项目前已经过处理；本项目不做 ERP 系统对接、不做 ERP 导出数据清洗。
- **范围说明**：本变更为系统底座；生产管理、库存管理、质量管理三个业务模块由后续独立变更提案承接；企业知识库、多用户登录不在本次范围。
