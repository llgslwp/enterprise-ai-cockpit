# Spec Delta

## ADDED Requirements

### Requirement: 启动就绪等待
系统 SHALL 在启动脚本中等待后端服务真正就绪后再打开浏览器，以避免浏览器早于后端就绪导致用户登录时连接被拒、误报「登录失败」。

#### Scenario: 后端就绪后才打开浏览器
- **WHEN** 用户运行一键启动脚本启动驾驶舱
- **THEN** 启动脚本 MUST 轮询等待后端 8000 端口进入 LISTEN 状态后，才打开浏览器指向前端地址

#### Scenario: 后端未就绪时明确提示
- **WHEN** 启动脚本在等待超时（60 秒）后后端仍未就绪
- **THEN** 启动脚本 MUST 明确提示「后端未就绪」，而非让用户在不知情下直接登录
