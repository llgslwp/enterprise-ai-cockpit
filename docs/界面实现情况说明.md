# 企业 AI 驾驶舱 · 界面实现情况说明

> 本文档只描述界面「长什么样、能做什么、不能做什么」，不涉及技术实现细节。
> 整理时间：2026-11-02

---

## 一、整体界面布局

打开系统后，是一个**左侧菜单栏 + 右侧内容区**的布局：

- 左上角为「企业 AI 驾驶舱」品牌名
- 左侧一列竖排菜单，从上到下依次为：
  1. 汇总看板
  2. 文件上传
  3. 生产计划
  4. 生产缺口统计
  5. 库存管理（可展开）
  6. 质量分析
- 菜单最下方是「退出登录」按钮
- 右侧为当前菜单对应的页面内容
- 右下角有一个「AI 助手」浮窗/入口

其中「库存管理」可展开出 4 个子菜单：**库存总览、库存占比、库存明细、缺口统计**。

---

## 二、各页面具体表现

### 1. 汇总看板（首页）
- 标题「汇总看板」，副标题「总经理端口：查看各业务数据的汇总，KPI 指标待后续确定」
- 有 4 个灰色卡片，分别标注「本月产量」「库存周转」「排产达成」「质量合格率」
- 卡片上的数字均为「—」（横杠占位符）
- **现状：基本是空占位页，无任何真实数据**

### 2. 文件上传
- 标题「文件上传」，副标题「保管员端口：上传 ERP 导出的库存 Excel 文件」
- 中间一个虚线框，提示「点击选择或拖入 Excel 文件」，可点选电脑上的 Excel 上传
- 下方列出「已上传文件」清单
- **现状：目前唯一能「往里送数据」的操作入口（上传 Excel 文件）**

### 3. 生产计划
- 深色科技感大屏（深蓝底、发光标题）
- 顶部标题「生产计划管理」，蓝色标签显示「2026年X月总生产计划」，右上角一排月份切换按钮（最新 / 2026-08 / 2026-09 / 2026-10 等）
- 中部 5 个大数字卡：总体完成率 + 4 个维度（历史 / 当月库存 / 当月订单 / 世达）的完成率
- 下方 6 个环形图，对应 6 个品种（加力钳 / 美钳 / 含钛 / 内管钳 / 钻杆钳 / 套管钳），环形图中间显示完成百分比
- 再下方 4 个环形图，对应 4 个维度
- **现状：纯展示页，只能切换月份看数据，无任何「操作/执行」按钮**

### 4. 生产缺口统计
- 标题「生产缺口统计」，副标题「V2.0 排产结果直显」
- 顶部一排品类切换按钮：加力 / 美式 / 内管钳 / 钻杆钳 / 套管钳
- 下方一张大表格，横向列包括：配件名称、规格、毛坯库、机加工、热处理、待处理、外协、半成品、装配、成品计划、半成品需求计划、装配缺口、机加工生产计划
- 表格带颜色（成品计划蓝底、装配缺口正数粉红底红字等），复刻 Excel 样式
- 部分行显示「见XX」表示借用关系
- **现状：纯展示页，只能切换品类看表格，无操作按钮**

### 5. 库存管理（4 个子页面，均为深色大屏）

| 子页面 | 表现 |
|---|---|
| 库存总览 | 3 个数字卡（入库 / 出库 / 库存总数）+ 柱状图 + 占比环形图 |
| 库存占比 | 6 张环形图（入库 / 出库 / 结存 各自按品种和两大系列） |
| 库存明细 | 重点规格明细表（只显示勾选的 30 个重点规格） |
| 缺口统计 | 库存预警表（低于安全库存的清单） |

- **现状：全部纯展示页，只看数据，无操作**

### 6. 质量分析
- 标题「质量分析」，副标题「质检员端口：查看质量管理数据的分析（职责待细化）」
- **现状：基本是空白占位页，无实际内容**

---

## 三、界面上「能做什么」和「不能做什么」

### 能做的（仅两个「动作」）
1. 上传 Excel 文件（文件上传页）
2. 切换月份 / 切换品类 / 展开菜单（均属「切换视角」，并非「执行生产操作」）

### 不能做的
- 界面上**没有任何一个按钮**能「执行排产」「执行回填」「生成排产结果」「写回数据」等**真正的生产操作**
- 生产计划、缺口统计、库存等页面，都是**「读现成的结果文件并展示」**，而非「在系统里点一下、跑一遍生产计算」

---

## 四、核心结论

生产管理最重要的「排产」动作，目前**只能靠人手动在后台跑脚本完成，界面上完全没有入口**。

用户在浏览器里看到的「生产计划」「缺口统计」，看的是**之前手动跑脚本留下的结果**，而不是「在系统里点出来的结果」。
