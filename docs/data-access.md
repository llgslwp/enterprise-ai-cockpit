# 数据接入约定

本文件固化系统底座（system-foundation）的数据接入边界契约，是 `data-access` 能力的落地文档。

## 三条边界（硬约束）

1. **不做 ERP 系统对接**：本项目不通过接口与 ERP 系统实时对接，不从 ERP 直接读取数据。
2. **不做数据清洗**：进入本项目的数据已经过上游处理，本项目不执行 ERP 导出数据的清洗工作。
3. **数据进入前已处理**：数据的清洗、纠错、去噪等职责归属数据进入前的上游环节，本项目仅负责消费已处理的数据。

## 数据入口

- 已处理数据统一放入 `data/` 目录。
- 具体载体（Excel / CSV / 数据库等）由后续生产管理模块提案时确定。

## 校验标准

- 代码中 MUST NOT 出现 ERP 接口对接相关代码路径。
- 代码中 MUST NOT 出现 ERP 导出数据的清洗逻辑。
